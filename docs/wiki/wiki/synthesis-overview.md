# 心智化治疗全景 MBT Overview

> **一句话**: MBT 是一套以"心智化（理解自己与他人心灵的能力）"为轴心的原则驱动心理治疗——其理论基石是心智化维度、非心智化模式、异化自体与认知信任，其临床核心是用 MBT 循环恢复依恋情境下的心智化能力。

## 摘要
本页是 Wiki 的入口与概念地图，将 [[source-mbt-cambridge-guide]] 全书（18 章、4 部分）浓缩为可导航的知识网络。MBT 由 Bateman 与 Fonagy 于 1990 年代创立，最初针对 BPD，现已发展为覆盖人格障碍、抑郁、精神病、创伤、进食障碍及儿童、青少年、家庭、伴侣、社区与紧急照护的跨诊断框架。

## 理论基石（为什么有效）
1. **心智化（[[concepts/concept-mentalization]]）**：理解自我与他人心灵的能力，双刃剑——其失效即一切精神障碍易感性的代价。
2. **心智化维度（[[concepts/concept-mentalizing-dimensions]]）**：自动/受控、自体/他人、认知/情感、内部/外部；好心智化=灵活平衡。
3. **非心智化模式（[[concepts/concept-non-mentalizing-modes]]）**：精神等同、目的论、假装——心智化"离线"的三种状态，是干预靶点。
4. **异化自体（[[concepts/concept-alien-self]]）**：高压下"非我"体验，与解离、自伤/自杀相连。
5. **依恋与认知信任（[[concepts/concept-attachment-epistemic-trust]]）**：依恋激活抑制心智化；认知信任是 MBT 机制枢纽（"我们-模式"）。
6. **跨诊断视野（[[concepts/concept-psychopathology-mentalizing]]）**：p 因素、DMN、情绪失调、过度/不足心智化。

## 临床模型（怎么做）
- **MBT 概述（[[concepts/concept-mbt]]）**：12–18 个月，个体+团体，原则驱动。
- **心智化立场（[[concepts/concept-mentalizing-stance]]）**：不知道/好奇 + 真诚/真实。
- **MBT 循环（[[concepts/concept-mbt-loop]]）**：命名低心智化→好奇探索→重新叙述。
- **核心临床技术（[[concepts/concept-clinical-techniques]]）**：验证、反向移动、停车、倒带、情感聚焦、关系心智化、反-关系等。
- **评估与个案概念化（[[concepts/concept-formulation-assessment]]）**、**治疗结构（[[concepts/concept-mbt-structure]]）**、**MBT 团体（[[concepts/concept-mbt-group]]）**。

## 关键洞察（AI 综合）
- MBT 的"普通话"隐喻（张天布推荐序）：心智化是各心理治疗流派可共享的通用话语系统。
- "依恋被触发，心智化就脆弱"——这是 BPD 治疗难点的神经与临床核心。
- 过度确定性是心智化不佳的最明显指标；保持谦逊是治疗师的基本姿态。
- 从 BPD 单一适应证到跨诊断：p 因素与 DMN 把心智化困难统合为广义精神病理的共同易感性。
- 危机/创伤中异化自体占据心智，自伤/自杀常是"最后可用的能动性"——恢复需先共情降级再重建叙事。
