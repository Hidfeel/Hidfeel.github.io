# 核心临床技术 MBT Clinical Techniques

> **一句话**: MBT 拥有一组命名干预技术，围绕"识别低心智化→用 MBT 循环重新点燃心智化→在有效心智化中重新叙述"展开，并针对高风险情境有专门的倒带与功能分析技术。

## 摘要
本章汇总 MBT 各章中出现的核心命名技术。它们不是孤立技巧，而是服务于"保持/恢复心智化"这一目标的协调工具箱。与 [[concepts/concept-mbt-loop]]、[[concepts/concept-mentalizing-stance]]、[[concepts/concept-non-mentalizing-modes]] 紧密关联。

## 详情

### 基础立场与认可
- **共情性认可 / 验证（empathic validation）**：用或然的、标记性的反应认可患者情绪可被共鸣及其影响，是所有干预的基础，在确认与辩论间走中间路线。
- **"不知道"的立场（not-knowing stance）**：好奇探索他人心智、不把自身心理视为特权；制造反思张力、激发想象力；问"如何"而非"为什么"（见 [[concepts/concept-mentalizing-stance]]）。
- **心智化沟通 / 询问（mentalized asking / communication）**：治疗师平等分享自身心理状态、用好奇"如何"提问、示范"不知道"立场的双向沟通。
- **标记性镜映（marked mirroring）**：他人反应启动校准内部体验、整合情绪反应到自我图像，是重建自我理解的社会过程（见 [[concepts/concept-alien-self]]、[[topics/topic-mbt-children]]）。

### 过程管理
- **反向移动（contrary moves）**：在心智化四维两极间推动患者移动，改善自体/他人等分化的灵活性（见 [[concepts/concept-mentalizing-dimensions]]）。
- **停车 / 停顿（parking / STOP）**：治疗小节中暂停、回溯互动，给低心智化"停车"以恢复心智化再继续。
- **倒带 / 时间倒带（rewind / time rewind）**：高风险事件后回溯到患者心智化仍稳定的时点，找脆弱点（见 [[concepts/concept-mbt-loop]]、[[topics/topic-mbt-emergency]]）。
- **情感聚焦（affect focus）**：澄清、情感识别、对事件的功能分析；核心是识别"房间里的大象"（见下）。
- **微观切片 / 心智化功能分析（micro-slicing / mentalizing functional analysis）**：极慢极细地讨论事件中主观体验变化，含元认知、一阶/二阶/代理心智化，聚焦"当时你在想什么"。

### 命名与叙事
- **命名和记录（name and record）**：识别低心智化模式即贴标签（如"头脑爆炸""由外而内的心智"），提高患者敏感度以便提前阻止。
- **MBT 循环（MBT loop）**：命名低心智化→好奇探索拓宽→在有效心智化中重新叙述（见 [[concepts/concept-mbt-loop]]）。
- **心智化情感叙事（mentalizing affect narrative）**：将低心智化个人叙事转为连贯、有自我同情的心智化版本。
- **房间里的大象（elephant in the room）**：识别未被言明的次主导叙事/关系张力，富同情语言化以增加认知信任、激发关系心智化。

### 关系层面
- **关系心智化（relational mentalizing）**：探索患者-治疗师当前关系，双方并排观察想法感受、分担责任、达成替代视角，替代移情诠释。
- **反-关系心智化 / 反-响应性（counter-mentalizing / counter-responsiveness）**：治疗师表达自身关于患者内在体验的感受，标记为自身心理状态一面，不归因于患者（见 [[topics/topic-mbt-npd]]、[[topics/topic-mbt-aspd]]）。
- **假装模式干预（含治疗性伏击 therapeutic ambush）**：对假装模式用命名、增加关系焦虑、反事实挑战、轻松调皮的突袭打破独白伪装（须基于同情与认知共情、在稳固联盟下使用）。

### 安全与责任（高风险）
- **共担责任（shared responsibility）**：危机协议中明确治疗师与患者各自责任范围，不单方承担患者行动责任。
- **安全性规划（safety planning）**：事实调查自伤/自杀事件的前-中-后细节与当前风险水平。
- 详见 [[topics/topic-mbt-bpd]]（"有风险的"患者）、[[topics/topic-mbt-adolescents]]（危机计划）、[[topics/topic-mbt-emergency]]（四步骤）。
