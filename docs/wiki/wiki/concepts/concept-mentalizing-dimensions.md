# 心智化维度 Dimensions of Mentalization

> **一句话**: 心智化运作于四对极性（维度）之上；好的心智化=在每对两极间灵活移动并取得平衡，所谓"崩溃"因个人落点不同而呈现不同样貌。

## 摘要
心智化动用不同的社会认知活动、以不同神经生物学过程为基础。MBT 用四个维度评估个体的"心智化概况"（mentalizing profile），维度失衡或僵化即构成脆弱点。注意：本书使用的是"内部的/外部的（internal/external）"，而非常见的"内隐/外显（implicit/explicit）"。

## 详情

### 1. 自动的 / 受控的（automatic / controlled）
- 多数时候自动（不加反思）进行；当注意到他人不开心时，会放慢到更有意识、受控地思考。
- 过度受控会让社交体验"很辛苦、不自然"。BPD 患者常表现自动心智化倾向（见 [[topics/topic-mbt-bpd]]）。

### 2. 自体 / 他人（self / other）
- 理解自己心理状态的能力不能视为理所当然。有效心智化要求意识到"他人心理状态与自己不同"。
- 卡在"他人"极→易被他人情绪淹没、易受剥削；很强的他人心智化但缺情绪共情→易虐待/剥削他人；过度关注自我→无法获得他人视角调节，社会联结减少。BPD 有自体/他人分化困难；自恋者夸大自体、贬低他人（见 [[topics/topic-mbt-npd]]）。

### 3. 认知的 / 情感的（cognitive / affective）
- 认知极=识别、标记、推理心理状态；情感极=对正在发生之事的"感受"。
- 卡在情感极而无认知标记→压倒性失调情绪、灾难化、对观念的特殊确定性；卡在认知极而缺感受→与现实脱节、变假装模式、缺真正共情（见 [[concepts/concept-non-mentalizing-modes]]）。

### 4. 内部的 / 外部的（internal / external）
- 外部=从面部表情等外部线索推断；内部=根据对他人内部状态（其知道/认为/相信什么）的想象来思考。
- 过度外部→过度警觉、寻求外部安慰、缺内部框架→"不知道"/空虚感、驱使自己寻求强烈体验填补；过度内部→无充分外部现实支撑的毫无根据推断（假装模式倾向）。

### 临床含义
- 好的心智化=在每维度两极间灵活"移动"并取得平衡。
- **反向移动（contrary moves）**：当患者偏重某极，治疗师鼓励阐述相反一极（如过度聚焦他人心智时引导其阐述自体），激发维度灵活性（见 [[concepts/concept-clinical-techniques]]）。
- 评估见 [[concepts/concept-formulation-assessment]]：暂时性失衡正常，仅当固定、僵化、过度或不足使用时才关注。
