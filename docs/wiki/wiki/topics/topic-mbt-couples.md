# 对伴侣进行工作 — MBT-CO

> **一句话**: 针对伴侣的 MBT（MBT-CO）将伴侣视为一个共享的共同心智化系统，通过恢复心智化与认知信任、重建安全基地/避风港来修复关系，核心是「关系本身」而非个人。

## 摘要

对许多人而言，伴侣关系是最恒定的共同心智化系统之一，熟悉感有助于日常自动心智化；但亲密关系激活依恋系统，往往会切断心智化，使非心智化模式的根深蒂固触发因素易被活现。MBT-CO（Mentalization-Based Treatment for Couples）由 Efrain Bleiberg、Ellen Safier 与 Peter Fonagy 共同开发，侧重示范、支持与恢复心智化及认知信任，特别适合思考和对伴侣工作。

MBT-CO 的核心是：治疗师治疗的是关系本身，而非个人；目标是营造可增强复原力与幸福感的「共同心智化」（we-mode，我们-模式）潜力。

## 详情

### 心智化立场 / 关键概念

- MBT-CO 围绕两个关键特征构建：①治疗师的心智化立场（「如何成为」）；②治疗师可采取的干预措施范畴（「做什么」）。
- 立场以「不知道」为特征，对心理状态开放、好奇、不评判。
- **保持平衡**：在心智化四个维度间灵活平衡——关注自体↔关注他人、情感↔认知、自动↔受控心智化、不同人的内/外部特征间的心智化；当压力与唤起降低时受控心智化才易运作。
- **打断非心智化**：非心智化在困难互动中作为防御机制出现，会引发消极螺旋；治疗师须识别崩溃（包括自身崩溃）并打断（如暂时休息）。
- **突显和标记心智化**：识别并标记一方/双方有效心智化的时刻（好奇、尊重、愿承担责任、表达脆弱而不防御）。

### 该模式的结构（形式、时长、阶段）

- **评估**：初步评估伴侣双方历史、功能及保持/恢复心智化位置的程度，含五项特质的存在程度——被认可理解感、「站在自己一边」的安全信任感、找到「认知性伙伴」、作为安全基地+避风港、在亲密与情欲「他人状态」（otherness）间平衡。探索何种互动破坏这些特质、何时心智化/信任崩溃。
- **会谈结构**：1–2 节联合伴侣治疗 + 每方 1–2 节个体治疗（评估依恋史、关系史、人格/功能/兼容性，及伴侣在场难谈的问题如物质滥用、不忠、创伤）；之后一次联合会谈提出书面/口头个案概念化；再进入心理教育与治疗结构（通常每周一次伴侣治疗 + 可选个体会谈，必要时转介个体治疗/药物/戒断治疗）。
- 概念化始终为「正在进行中的工作」而非最终文件，并用于引入心智化与认知信任理念。

### 关键干预技术 / 练习

- **共情、支持和认可**：不仅支持认可双方，也帮每方停止不认可对方、发展更共情的立场；以「一方对话、另一方倾听并尝试理解」为关系搭建心智化脚手架。
- **澄清、情感聚焦和详细阐释 / 倒带和反思（rewind & reflect）**：回溯并精准确定双方还能清晰思考、自由回应对方的最后时刻，进行**心智化功能分析**（mentalizing function analysis），阐述每人心理状态如何随互动时刻的意义变化，揭示隐藏的焦虑与易感性。
- **挑战与治疗谈判**：当双方能合作时用于存在假装模式的伴侣，尤针对忽视/淡化物质滥用、不忠、隐藏财务等破坏性行为；需技巧地面对分享易感性的不适。
- **在此时此地修复心智化与认知信任**：治疗师愿为自身错误/不同调承担责任，并教伴侣**有效道歉的规则**——修复裂痕首先是为「自己的伤害行为」而非对方的感受负责；先对伴侣观点感兴趣、容忍自己难免让对方失望的事实。
- **we-mode（我们-模式）**：通过共同安全基地与避风港，建立可推广至其他关系的社会学习良性循环。

### 临床案例简述

一对有幼童的伴侣：孩子拒绝吃某方准备的饭引发其与孩子对峙、烦躁沮丧；另一方试图安抚孩子打破僵局，却让前者感到被排斥，后者因被「串通」而恼怒。形成防御循环——出现目的论模式（孩子必须吃饭、对方必须喂饭以表达爱）与精神等同（一方因被拒感到受伤，视孩子与伴侣为敌意）。最初的亲子艰难互动演变为伴侣间危机，根源是对另一方意图缺乏信任。MBT-CO 通过评估五项特质、个案概念化与倒带反思，逐步恢复双方心智化与认知信任。
