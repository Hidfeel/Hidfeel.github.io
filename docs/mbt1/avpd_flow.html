时机 治疗技术时机总览
timeline
    title MBT-AvPD 治疗技术时机
    section 评估期
        不知立场 : 贫乏本身就是信息
        间接路径探索 : 通过物理世界进入主观性
        识别低/过度心理化 : 不挑战假装模式，共情其努力
    section 概念化期
        共同配方 : 6焦点明确列出并达成共识
        副作用预警 : 标注伪心理化风险，双方共同监测
    section 早期治疗
        共情确认 : 建立我们模式与认识论信任
        游戏与角色扮演 : 安全接近他者心理状态
        Mind-Brain Scan : 结构化多视角探索
    section 中期治疗
        自我→他者转换 : 对抗自我中心偏差核心工作
        4步多视角探索 : a-b-c-d逐步推进
        记忆精细化 : 从第三人称→第一人称意象
