关键要点

夸大型 vs. 脆弱型 自恋功能对比

🔴 夸大型 (Thick-Skinned / Grandiose)

  • 膨胀的自我重要感，需要持续钦佩
  • 认为自己特殊，只能与同等特殊者交往
  • 垄断对话，贬低他人
  • 习惯性特权感，期待特殊待遇
  • 傲慢、自夸、自命不凡
  • 干预核心：突然、游戏式挑战 + 反关系直接点名
  • 风险：治疗师产生反移情——觉得患者讨厌、傲慢

🟣 脆弱型 (Thin-Skinned / Vulnerable)

  • 持久的羞耻感与不安全感的表面防御
  • 极度害羞、回避、过度警觉
  • 对他人评价极度敏感
  • 需要不断从他人那里获取赞赏补给自尊
  • 焦虑型依赖，变色龙式模仿
  • 干预核心：高度共情支持 + 反对挑战（至少早期）
  • 风险：「假装 We-mode」——表面一致，内部脆弱

治疗师行动指南

✅ MBT-NPD 该做的

  • 将夸大部分框架化为治疗资源
  • 先建立 I-Mode，再触及 Me/We
  • 用治疗师自身担忧作为过渡引子
  • 对夸大型敢于游戏式挑战
  • 对脆弱型始终保持高度支持
  • 监控自己的反移情——隔离、理解、再利用
  • 关注互动中的非言语流——对话节奏失调
  • 早期阶段将挑战性反移情"隔离"

🚫 绝对不要做的

  • 在评估阶段就正面挑战夸大型自恋
  • 对脆弱型患者使用游戏式挑战
  • 陷入"Is this it? A professor?"式权力较劲
  • 忽略对话中的微妙失调（打断、贬低、节奏混乱）
  • 在 I-Mode 不稳时就进入关系工作
  • 被解雇策略激怒——患者即将产生认知警觉
  • 对"变色龙"患者的完全一致放松警惕
  • 忽略崩溃风险——Richard Cory 式突然自杀

关键概念：治疗中的「大象」

在 NPD 治疗中，治疗师的反移情反应（被傲慢激怒、感到被贬低）是不可避免的。 这不是治疗失败，而是临床材料。MBT-NPD 的处理方式是：

  1. 隔离（Quarantine）——先不行动，识别是什么激起了自己的反应
  2. 定义来源——这是对患者互动的自然反关系反应
  3. 反关系心智化使用——在适当时候（中后期），将其作为临床材料带入对话
  4. 不是报复——目的不是"战胜"患者，而是帮助患者看到互动模式
